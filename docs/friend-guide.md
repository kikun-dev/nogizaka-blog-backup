# SakaClip 友人向け利用案内

公開 URL は `https://sakamichi-blog-backup.vercel.app/` です。アクセスコードはこの案内とは別に、利用する本人へ個別に伝えてください。

## 使い方

1. `https://sakamichi-blog-backup.vercel.app/` を開き、個別に受け取ったアクセスコードを入力して「アクセスする」を押します。コードや URL を他の人へ渡さないでください。
2. 乃木坂46・櫻坂46・日向坂46から、保存したいブログの投稿者と記事を選びます。期別ブログ、運営スタッフ、ポカなども対象です。
3. 写真を保存する場合は「写真のみ」を選びます。取得後の写真は iPhone・iPad の Safari で長押しして「写真に保存」、Android の Chrome で長押しして「画像をダウンロード」できます。「写真をZIPで保存」も利用できます。
4. ブログを保存する場合は「ブログ」を選びます。完成した ZIP をダウンロードすると、PDF・MHTML・記事情報が入っています。iPhone では「ファイル」アプリで ZIP を開いて展開できます。

公開版は1回のジョブで写真が最大20記事、ブログが最大10記事です。全件バックアップや記事 URL の直接入力は利用できません。必要な記事だけを選び、同じ記事の取得を短時間に繰り返さないでください。

## 保存期限と停止中の動作

写真・ZIP は保存完了から24時間を過ぎるとアプリから取得できなくなります。必要なファイルは早めに端末へ保存してください。ダウンロード済みのファイルは端末側で管理してください。

取得処理は管理者のワーカーが動いている間に進みます。ワーカーが停止していると、ジョブは待機します。待機が続く場合や保存先への接続エラーが出る場合は、管理者へ連絡してください。失敗した記事がある場合は、結果画面の「失敗した記事だけ再試行」を使えます。コードの期限が切れた場合は、管理者へ連絡してください。

## 利用上のお願い

このツールは非公式の個人制作ツールで、各グループの公式サービスとは関係ありません。公式サイトに負荷をかけないよう、取得上限を守り、不要な連続実行を避けてください。ブログ本文や写真などの著作物の取り扱いには注意し、保存したファイルの転載・第三者への再配布はしないでください。
