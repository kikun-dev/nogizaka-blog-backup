# PR レビュー補助

PR 本文、関連 Issue、`main` との差分を読み、完了条件に対する実装・検証の証拠を確認する。セキュリティ、実行境界、エラー処理、既存 CLI への影響、将来の worker 差し替えに関わる変更を優先して調べる。差分と無関係な改善要求は混ぜない。

指摘は重大度（P0: マージ不可、P1: マージ前修正推奨、P2: 改善提案）、対象箇所、理由、修正方針を簡潔に示す。確認できない点は推測で断定せず「未確認」とする。問題が見つからなければ、その旨と残る検証上の制約を述べる。

レビュー結果を PR に投稿するかは依頼内容に従う。このスキルによるセルフレビューだけで必須のユーザーレビューを完了扱いにしない。
